### 🧱 What I Publish Here

| Content | What it contains |
| :-- | :-- |
| **Runnable examples** | Small, tested Java and Spring Boot examples that run from a clean clone |
| **Architecture decision records** | The problem, the options considered, the trade-offs, and the decision |
| **Failure-mode experiments** | Timeouts, retries, idempotency, and transaction behavior, tested under failure |
| **System design case studies** | Requirements and constraints first, then the design and its limits |

### ✅ Repository Standard

Every repository I publish meets this bar:

- [x] Runs from a clean clone with documented steps
- [x] Automated tests pass in CI
- [x] README includes an architecture diagram
- [x] Design decisions are recorded as ADRs
- [x] No secrets or private data in code or git history

### 🧭 Engineering Principles

> **Design for failure.** Timeouts, retries, idempotency, and clear error contracts come before features.
>
> **Tests are the specification.** Behavior is validated automatically, not assumed.
>
> **Decisions are written down.** Architecture choices are recorded with their trade-offs.
>
> **Secure by default.** Authentication, authorization, and secrets handling are part of the first design.
